# ACM: Agentic Context Management for Long Horizon Tasks

# 脉络
固定触发和不可恢复的上下文删除，难以跟上 Agent 随任务变化的推理关注点。

# 方法
- 为 Agent 提供上下文编辑工具，由其决定管理时机。
- 将移出活动上下文的内容保存到外部记忆，后续按需查询。
- 通过后训练流程学习上下文管理行为，评估搜索与代码任务。

# 对切入点的启发
联合考虑常驻 KV、外部文本记忆和按需重新读取：哪些内容值得保留在 KV，哪些可移出后再检索？

# 对照与边界
原文的 lossless 表述涉及内容可外存与恢复，不等于 KV 近似 Attention 无误差。应分别统计外存规模、检索成功率、重建/Prefill 时间和任务质量。
