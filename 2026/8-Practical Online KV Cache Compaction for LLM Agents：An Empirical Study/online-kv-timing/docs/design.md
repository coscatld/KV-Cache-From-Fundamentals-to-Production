# 实验设计与可观察信号

研究假设：在相同峰值缓存约束下，自适应时机可能改善任务质量—总耗时关系；不预设成立。

## 固定变量

单一固定 revision Llama、同一任务集合、系统提示、词重合度检索、greedy decode、seed、评分规则。所有策略共用 per-layer/per-head RMS Attention TE；代码中的 GQA Query 在同组 query heads 取均值后作为 KV-head 代理，是第一版工程约定，不等同于论文精确实现。

| 组 | 时机 | 保留比例 |
| --- | --- | --- |
| A_boundary | 每轮结束 | 0.2 |
| delay1/3/5 | 等待指定后续轮数 | 0.2 |
| T | 运行时规则 | 0.2 |
| R | 固定延迟 1 | 自适应 |
| TR | 运行时规则 | 自适应 |

当前实现以完整轮为压缩单元，assistant 和工具响应合成一个 segment，区别于论文分段压缩。prefix 全保护；模板边界保护；活动轮不压缩；历史压缩一次后冻结。protected 数量多于比例预算时提高实际保留数并记录实际 before/after；不通过删结构 token 硬凑名义比例。

## 信号与触发

Query 是 post-RoPE，来自已完成 assistant 生成；Boundary 来自本工程显式 EndTurn 分隔文本最后 token，不声称是模型原生聊天结束 token。Llama adapter 持有当前生成最多 32 个 feed 的 Query，已完成待压缩历史决定保留的 Query 窗口。

漂移：对一轮 Query 在 token 维求均值，展平层/head/特征后 L2 归一化；相邻轮均值的余弦距离 1−cos，范围 [0,2]。首轮设 1。全局位置本身也影响 post-RoPE 漂移；这只是可验证的低成本候选信号，不保证代表语义变化。

增长率：本轮已拥有缓存字节与上轮观测缓存字节的正差 / 缓存 cap。

自适应触发优先级：
1. 预计缓存使用超过 safety_fraction（默认 0.65）：安全强制压缩，允许覆盖最小间隔。
2. 普通触发须满足最小全局间隔（默认 1 轮）；历史年龄达最大间隔或全局间隔达上限（默认 5）则触发。
3. 达最小历史年龄且间隔合法后，Query 稳定（漂移 ≤ 0.15）或增长率 ≥ 0.1 时触发。

固定延迟在触及安全阈值时也回退，并记录 safety_pressure、实际年龄和 boundary/future 来源。仅使用已经完整观测的后续轮 Query；无 future 时用已知 boundary。每次压缩原因、漂移、增长率、比例、实际长度均在 events 中保存。

R 在固定触发时使用 rho=min+(max−min)×min(drift/2,1)，默认 [0.1,0.4]；安全压力下不超过基准 0.2。T 从不改变比例。TR 是 T 和 R 的组合实现，解释其质量收益必须先看 T/R 独立结果。

## 调参与冻结

selection.py 只访问 validation 任务进行候选评估，对 T 和 R 分别选择可行率 100%、无代码错误的候选，先最大化 exact match，再以较低平均墙钟时间打破平局。所有候选结果与搜索总时间保留，不进行静默筛除。搜索不能使用 synthetic 质量；若没有真实验证结果就不生成有效选择。

测试入口要求 frozen.json，校验数据和全部共同配置的 hash。baseline 保持默认固定，T/R 使用各自冻结参数，TR 使用 T 的触发参数、R 的比例上下限及同一显式比例公式。冻结文件是研究协议记录，不提供抵御人为修改文件的安全机制。更换参数意味着重新建立独立测试集。

## 配对与约束

任务 ID、种子、工具与生成设置相同。Agent 可能因压缩改变检索与轨迹，这是待测结果，不应强行复用同一生成轨迹。所有任务（含失败/不可行）保留在分母；未成功的任务按零分汇总。配对差异以 delay1 为基准；当前不计算显著性。多预算实验可复制共同配置、修改 peak_kv_bytes，在每个预算独立验证冻结后比较，不能让策略私自选择更大 cap。
