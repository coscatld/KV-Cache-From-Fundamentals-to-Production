# Scaling Long-Horizon LLM Agent via Context-Folding

# 脉络
长任务中，已完成子任务的完整中间轨迹未必需要一直占用当前工作上下文。

# 方法
- Agent 为子任务建立分支轨迹，完成后折叠中间过程，只保留简洁结果。
- 使用 FoldGRPO 和过程奖励学习任务分解与上下文管理。
- 研究场景包括 Deep Research 与软件工程任务；操作对象是活动文本上下文。

# 对切入点的启发
把子任务完成作为候选压缩边界，与固定轮数触发比较，检验任务阶段是否能预测历史内容的未来复用。

# 对照与边界
文本折叠与 KV 压缩的计算路径不同。需要计入阶段识别、摘要生成和重新读取成本，并证明阶段信号对 KV 决策有独立贡献。
