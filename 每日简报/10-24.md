## 论文
### 1.Latent Briefing

url： https://labs.ramp.com/research/latent-briefing-kv-cache/?utm_source=chatgpt.com#citation
使用编排器的任务提示产生 Query，通过这些 Query 与历史轨迹 Key 的注意力关系，评估历史内容对当前 Worker 任务的相关性，再进行 KV 压缩。
### 2.TMA

url： https://arxiv.org/abs/2608.12331
把 **近期 Query 引导的 AM** 变成结构感知压缩：先按推理步骤划分历史，再根据重要性和长度分配保留预算，保护关键 Token，最后对选出的 Key 统一拟合 AM 与输出。**分段的是选 Key 和预算，全局进行的是偏置与 Value 拟合。**

## idea

我们的场景是“在线压缩，agent”。我之前第一个项目有关于长记忆agent，所以我就想能不能讲agent长上下文管理的思想搬到KVcache压缩，然后我就找GPT搜索相关论文。

我认为长期记忆系统中最值得借鉴的是“状态驱动检索”和“分层记忆管理”，在长期记忆研究和我们的研究的存储对象和优化目标，但是在一个可以利用的共同点：历史信息的价值不是固定的，而是取决于 Agent 当前处于什么状态，以及接下来需要完成什么任务。

所以我的想法是借助agent的状态信号（当前任务进展、目标、约束），而不是代理信号，来驱动压缩
